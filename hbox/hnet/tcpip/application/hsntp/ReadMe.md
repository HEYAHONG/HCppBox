# 说明

本目录主要用于辅助实现简单NTP(Simple NTP),由[RFC 5905](https://www.rfc-editor.org/rfc/rfc5905.html)描述。

NTP主要采用UDP协议，其按照包进行处理，每次用户均需要直接发送或者接收单个完整的包(包含多个字节，最大支持长度受网络MTU限制，保守值为548字节)，其校验由UDP层完成。

本组件每次传入传出的数据也必须是一个完整的数据包。

# 简单NTP

简单NTP并未完全使用NTP的算法,通常用于要求不高的场合。

## 客户端

采用服务器的发送时间作为标准时间。

## 服务端

接收到数据包后，进行以下操作：

- 将模式改为服务端。
- 将服务器接收时间与发送时间修改为当前时间。
- 发送修改后的数据包。
