# 说明

本目录主要用于辅助实现HTTP/1.1(或HTTP/1.0)。

HTTP/1.1(或HTTP/1.0)主要使用文本传输数据，最小单位为以\r\n结尾的行。

HTTP参考文件:

- [RFC9110](https://www.rfc-editor.org/rfc/rfc9110.html)
- [RFC9112](https://www.rfc-editor.org/rfc/rfc9112.html)

HTTP/1.1(或HTTP/1.0)主要采用TCP协议，其主要按照数据流处理数据，最小的单位是字节。

HTTP/1.1(或HTTP/1.0)协议中主要分为服务端与客户端。服务端通常监听特定端口（如80、443），向外部提供服务。客户端通常连接服务端端口，发送请求并读取数据。

# 服务端

服务端主要组成如下：

- 文件：响应客户端请求的主体（body）内容。
- 会话：每次请求可以看作一次会话，会话处理客户端请求并提供响应，处理文件的打开与关闭。
- 虚拟主机：通过Host头部字段区分不同的虚拟主机，每次请求对应唯一的虚拟主机，产生有且仅有一次会话。
- 服务：每个TCP端口仅对应一个服务，但单个服务可以对应多个TCP端口。服务中至少包含一个虚拟主机用于产生会话。
- 连接：客户端每打开一个TCP连接便产生一个HTTP/1.1(或HTTP/1.0)连接，HTTP/1.1(或HTTP/1.0)连接与TCP连接一一对应。单个连接至少可以处理一次客户端请求，指定连接保活（keep-alive）时可进行多次请求。

## tinyserver

仅支持简单的请求，不支持复杂的请求（如代理转发等）
