# 说明

本组件用于辅助实现[DL/T 645](https://std.samr.gov.cn/)标准。

DL/T 645采用主从模式，默认情况下采用RS-485总线标准（串口参数为8E1），帧间隔大于20ms小于500ms（字符间间隔小于500ms）,非标实现时也可采用TCP/IP协议转发串口数据。

# 从机

## 可外部配置的宏定义

| 宏定义                              | 说明                  | 备注                                   |
| ----------------------------------- | --------------------- | -------------------------------------- |
| `HDLT645_SLAVE_IO_NO_TX_BUFFER`     | 不单独分配发送缓冲区  | 定义此宏定义后，将使用栈作为发送缓冲区 |
| `HDLT645_SLAVE_TIME_SYNC`           | 时间同步              | 若不定义则采用`hsettimeofday`设置时间  |
| `HDLT645_SLAVE_DI_TABLE`            | 数据标识表指针        | 当对读写的数据表单独设置时无效         |
| `HDLT645_SLAVE_DI_TABLE_SIZE`       | 数据标识表长度        | 当对读写的数据表单独设置时无效         |
| `HDLT645_SLAVE_READ_DI_TABLE`       | (读取）数据标识表指针 |                                        |
| `HDLT645_SLAVE_READ_DI_TABLE_SIZE`  | (读取）数据标识表长度 |                                        |
| `HDLT645_SLAVE_WRITE_DI_TABLE`      | (写入）数据标识表指针 |                                        |
| `HDLT645_SLAVE_WRITE_DI_TABLE_SIZE` | (写入）数据标识表长度 |                                        |
| `HDLT645_SLAVE_WRITEADDR`           | 写入通信地址          |                                        |

## 数据项

每个数据项由数据标识标识。

数据标识中字节中为0xFF通常表示数据块读取，因此一般要求单个数据项（非数据块）的数据标识中所有字节不得为0xFF。

一般情况下，数据项的大小是固定的。受限于最大写入数据的数据长度限制，单个数据项的大小不得超过38字节（最大写入长度-数据标识长度-密码长度-操作者长度）。对于不支持写入的数据项，单个数据项的大小不得超过196字节（最大读取长度-数据标识长度）。

## 调用关系

本组件中从机分为IO端口及上下文。每个IO端口对应单个硬件（如串口），单个上下文可关联多个IO端口。

- IO端口及上下文的初始化均有主线程（或IO处理线程）完成。
- IO端口的数据输入(`hdlt645_slave_io_rx_input`)可由中断完成。
- 上下文的处理函数( `hdlt645_slave_io_ctx_process_io`)必须在主线程（或IO处理线程）中循环调用。
